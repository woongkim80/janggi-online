# ♟️ 천하명인 온라인 장기 (Janggi Online)
> **Google 계정 연동 & 실시간 1:1 대전 및 관전자 훈수 지원 한국 전통 장기 웹 플랫폼**

---

## 🌟 주요 특징 및 기능

1. **한국 전통 장기 룰 엔진 100% 구현**
   - 9×10 격자 보드 모델링 및 초(楚) vs 한(漢) 진영
   - 한국장기협회 공식 4대 포진 선택 (마상마상, 상마상마, 마상상마, 상마마상)
   - 마/상 멱 차단 판정, 포 도약 및 포끼리 넘기/잡기 금지, 궁성 대각선 이동
   - 실시간 공식 점수 집계 (차 13점, 포 7점, 마 5점, 상 3점, 사 3점, 졸/병 2점, 한나라 덤 1.5점)

2. **컴퓨터(AI) 대전 모드**
   - 1-Ply Minimax 및 점수 우위 평가 기반 인공지능 탑재
   - 플레이어가 수를 두면 컴퓨터가 실시간으로 최선의 수를 탐색하여 자동 응수

3. **Google 로그인 및 ELO 레이팅 시스템**
   - 구글 계정 간편 로그인으로 닉네임, 프로필, 전적(승/패/승률) 영구 기록
   - 승패에 따른 ELO 레이팅 점수 자동 가감

4. **실시간 대전방 및 관전(Spectator) 모드**
   - 방 개설 및 룸 코드 기반 자유로운 입장
   - 관전자 실시간 시청 및 우측 **훈수/응원 채팅창** 지원
   - 착수 기보(Move History) 실시간 기록 및 복기

---

## 🚀 로컬 실행 방법

```bash
# 1. 의존성 패키지 설치
pip install -r requirements.txt

# 2. 애플리케이션 실행
streamlit run app.py
```
또는 윈도우 환경에서 `run_janggi.bat`을 더블 클릭하면 즉시 실행됩니다.

---

## 🛠️ 기술 스택
- **Language**: Python 3.11+
- **Frontend / Framework**: Streamlit
- **Database**: SQLite (`janggi.db` 단일 파일 기반 영구 저장)
- **AI / Game Logic**: Pure Python 장기 룰 엔진 & Minimax AI
